# Contributing to GameForge

Thanks for your interest in contributing to GameForge.

GameForge is an open-source toolkit for indie game developers, and contributions are welcome.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Create a new branch for your change.
4. Make your changes.
5. Run the test suite.
6. Open a pull request.
