# GameForge

Open-source toolkit of reusable systems and utilities for indie game developers.

## Features

- Inventory management
- Quest management
- Achievement tracking
- Game-state management
- Lightweight, dependency-free modules
- Automated tests with GitHub Actions
- ES module support
